# Klikbar prototype

`index.html` er en selvstændig, klikbar prototype af UX-flowet for MVP 1–3
med Sander som eksempeldata. Ingen AI-providere er koblet på: brief,
storyboard, billeder og video er simulerede, og data gemmes kun i browserens
localStorage ("Nulstil demo" starter forfra).

Den er et designgrundlag, ikke produktionskode — MVP 1 bygges i `src/` og
`supabase/` efter `docs/arkitektur.md`.
